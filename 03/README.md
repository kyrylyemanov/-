# Звіт до роботи

## Тема: Покриття коду

## Мета роботи

Навчитися вимірювати покриття коду тестами, перевіряти покриття рядків і розгалужень, формувати звіти та встановлювати мінімальний поріг покриття.

---

## Виконання роботи

1. Створено [app.py](app.py) з класом `Figure`. Властивість `get_angles` повертає кути квадрата, прямокутника або трикутника. Конструктор відхиляє невідомий тип фігури через `ValueError`.
2. У [test_app.py](test_app.py) створено чотири тести: для квадрата, прямокутника, трикутника та невідомого типу.
3. У [.coveragerc](.coveragerc) налаштовано аналіз розгалужень, звіт без тестових файлів і мінімальний поріг покриття 90%. У [.gitignore](.gitignore) додано службові файли та папки, зокрема `.coverage`, `htmlcov/`, `__pycache__/` і `.pytest_cache/`.
4. Залежності для тестування та вимірювання покриття записано у [requirements-dev.txt](requirements-dev.txt).

### Команди запуску

Встановлення залежностей у віртуальне середовище:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-dev.txt
```

Запуск тестів:

```powershell
pytest -v
```

Запуск тестів із вимірюванням покриття рядків і розгалужень та перевіркою порогу:

```powershell
pytest --cov=app --cov-branch --cov-fail-under=90 --cov-report=term-missing -v
```

Альтернативно, за допомогою `coverage.py`:

```powershell
coverage run -m pytest
coverage report -m
coverage html
```

HTML-звіт створюється у `htmlcov/index.html`. Він є локальним службовим результатом і не додається до репозиторію.

### Результати

Перед додаванням перевірок для квадрата, прямокутника та невідомого типу запущено лише тест трикутника. Отримані результати:

- покриття рядків — **77%**;
- покриття розгалужень — **50%**;
- сумарний показник coverage.py — **68%**;
- пропущені рядки `app.py` — **9, 16 і 18**: відхилення невідомого типу фігури та гілки повернення кутів квадрата й прямокутника.

Поріг 90% на цьому етапі не досягнуто, тому coverage повідомив про невдалу перевірку порогу, хоча тест трикутника пройшов.

Після додавання тестів для решти випадків усі **4 тести пройшли**. Підсумкове покриття `app.py` — **100% рядків і 100% розгалужень**. Мінімальний поріг 90% виконано. Також сформовано HTML-звіт.

### Покриття рядків і розгалужень

Покриття рядків показує, чи виконувався кожен рядок програми. Покриття розгалужень показує, чи пройшло виконання кожним можливим переходом умов. Тому виконаний рядок умови не обов'язково означає, що перевірено всі її гілки.
