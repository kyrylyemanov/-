# Звіт до роботи

## Тема: Загальне тестування та юніт-тести

### Мета роботи

Навчитися перевіряти введені дані та тестувати функції й класи за допомогою unittest.

---

### Виконання роботи

У [app.py](app.py) я створив клас Figure, функцію підрахунку голосних count_vowels() і функцію read_positive_integer() для перевірки введеного числа. Клас перевіряє тип фігури й додатність довжини. Якщо користувач вводить нуль або від'ємне число, функція повідомляє про помилку; нечислове введення відхиляється під час перетворення на ціле число.

У [test.py](test.py) я написав 10 тестів для звичайних, порожніх, граничних і неправильних даних. Перевірив підрахунок українських голосних у слові, порожньому рядку, рядку з цифрами та великими літерами. Також протестував кути квадрата, прямокутника й трикутника. У цьому прикладі трикутник вважається рівностороннім, бо для його створення передається лише одна довжина.

Для кількох типів фігур використав subTest: якщо перевірка не пройде, буде видно, який саме набір даних спричинив помилку. За допомогою patch підмінив input(), тому перевірку введення можна виконати автоматично, без ручного набору.

Ось приклад перевірки твердження через assert:

```python
number = 5
assert number > 0, "Число має бути більшим за нуль!"
```

assert зручний для перевірок під час розробки. Для некоректного введення у програмі я використав ValueError.

#### Запуск і результати тестів

З папки example/testing/01_general_and_unittest тести запускаються командами:

```powershell
python test.py
python -m unittest -v
```

Перший запуск допоміг знайти помилку: для довжини 5 властивість get_figure_length повертала 6. Три підперевірки subTest показали її для кожного типу фігури. Також я помітив, що неправильно задав очікувану кількість голосних у рядку "Привіт, Україно": їх там шість, а не чотири. Я виправив реалізацію та очікуване значення тесту.

Після виправлень обидві команди завершилися успішно:

```text
Ran 10 tests
OK
```

Робота консольна, тому скриншотів немає; результат підтверджено виводом тестів.

### Висновок

- **Що зроблено:** написав функції перевірки введення й підрахунку голосних, клас `Figure` та тести до них.
- **Чи досягнуто мети:** так, я перевірив програму за допомогою unittest.
- **Що нового дізнався:** навчився перевіряти винятки, використовувати subTest і підміняти input() через patch.
- **Чи відповів на запитання з роботи:** так, у звіті наведено приклади перевірки даних і тестування.
- **Чи виконав завдання:** так, усі тести після виправлень завершилися успішно.
- **Чи були складнощі:** так, спочатку тест знайшов помилку в довжині фігури, а я неправильно порахував голосні в одному з очікувань. Обидва моменти виправив.
- **Відгук про формат:** мені сподобалося, що тести одразу показують, де саме виникла помилка.
- **Що можна покращити:** додати для фігур більше параметрів, щоб тестувати трикутники й прямокутники різних форм.
